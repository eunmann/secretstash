## Configuration

Configure your AWS SDK to point to the local endpoint:

### Environment Variable (Recommended)

```bash
export AWS_ENDPOINT_URL_SECRETS_MANAGER=http://localhost:18080
```

Then use your AWS SDK normally - no code changes required.

### Programmatic Configuration

For AWS SDK v2 (Go):

```go
import (
    "github.com/aws/aws-sdk-go-v2/aws"
    "github.com/aws/aws-sdk-go-v2/config"
    "github.com/aws/aws-sdk-go-v2/service/secretsmanager"
)

cfg, _ := config.LoadDefaultConfig(ctx)
client := secretsmanager.NewFromConfig(cfg, func(o *secretsmanager.Options) {
    o.BaseEndpoint = aws.String("http://localhost:18080")
})
```

For boto3 (Python):

```python
import boto3

client = boto3.client(
    'secretsmanager',
    endpoint_url='http://localhost:18080',
    region_name='us-east-1'
)
```

For AWS SDK v3 (Node.js):

```javascript
import { SecretsManagerClient } from "@aws-sdk/client-secrets-manager";

const client = new SecretsManagerClient({
  endpoint: "http://localhost:18080",
  region: "us-east-1"
});
```

## Integrating Into Your Project

Add to your `docker-compose.yml`:

```yaml
services:
  secretstash:
    image: ghcr.io/eunmann/secretstash:latest
    ports:
      - "18080:18080"
    volumes:
      - secrets-data:/data

volumes:
  secrets-data:
```

Available versions:
- `latest` - Latest stable release
- `v0.1.0` - Specific version (recommended for production)

## Supported Operations

Basic operations:
- CreateSecret, GetSecretValue, PutSecretValue, UpdateSecret, DeleteSecret
- DescribeSecret, ListSecrets, RestoreSecret
- TagResource, UntagResource

Advanced operations:
- UpdateSecretVersionStage, ListSecretVersionIds
- RotateSecret, CancelRotateSecret
- GetRandomPassword, BatchGetSecretValue
- ReplicateSecretToRegions, RemoveRegionsFromReplication, StopReplicationToReplica
- ValidateResourcePolicy

## Environment Variables

- `PORT` - Server port (default: 18080)
- `PERSISTENCE_FILE` - Path to JSON persistence file (default: /data/secrets.json)
